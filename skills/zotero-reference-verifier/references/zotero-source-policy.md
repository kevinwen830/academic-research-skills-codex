# Zotero Source Policy

Use this reference when deciding whether a bibliography item is safe to cite.

## Collection Policy

Prefer source pages in this order:

1. DOI or publisher landing page for the article.
2. PubMed, arXiv, official conference/proceedings, institutional repository, or library catalog.
3. Crossref, OpenAlex, Semantic Scholar, WorldCat, ISBN registries, or equivalent metadata services.
4. Google Scholar result pages as discovery leads only.

Zotero Connector is the preferred capture mechanism because it reduces manual entry and can attach metadata/PDFs, but imported metadata must still be checked against identifiers or source pages.

## Google Scholar Limits

Google Scholar is useful for finding papers and citation trails. Do not use it as the only verification source for:

- exact author order,
- article title capitalization or subtitle,
- journal issue/page metadata,
- publication status,
- retracted/withdrawn status,
- whether a source actually supports a claim.

Avoid large automated Google Scholar saving runs. Save small batches or use database export formats when available.

## Verification Minimums

To mark an item `verified`, confirm at least:

- stable identifier or stable source URL,
- title,
- first author or author list,
- year,
- venue or publisher,
- item type.

For claim-level verification, also confirm that the cited source actually contains the claim, preferably by checking the abstract/full text/publisher page rather than bibliography metadata alone.
